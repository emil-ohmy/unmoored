# Set pieces before progression

As of 2026-11-01 the user is building every set piece (enemies, abilities, Area moments, traps) as test material in
the labs. Only after that will they piece the game together and decide how the player progresses through it.

**Why:** the user pushed back when Claude suggested "hiding the Vault in the Drowned City" as a next step. Where things
live in the real game is a later decision. On 2026-11-02 they said the same of tutorials: "We'll fix tutorials when we
create the real levels, we need all set pieces first."

The exception, by the user's own choice (2026-11-02): the Hold, the game's opening, is being built as a real level
from the level editor (see [where we left off](where-we-left-off.md)). Work on it when the user asks.

**How to apply:** when suggesting what's next, propose set pieces to build and try in a lab. Don't suggest placing
abilities, wiring gates, teaching beats or tutorials elsewhere, or deciding the order of progression, unless the user
asks for it.
